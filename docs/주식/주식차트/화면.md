# 화면
`docs/주식/주식차트/화면.drawio` 파일참조

종목코드 : 입력상자로 미국주식 ticker를 입력
          입력값이 없거나 틀린 ticker를 입력시 에러메세지를 출력

종목검색 : 종목코드를 기준으로 조회           
          일/주/월 버튼중 활성화된걸 기준으로 yfinance(backend)를 이용해서 조회. 활성화버튼이 없으면 일기준으로 표시
          가져올 데이터는 open,close,low,hight,volumne

기간 : select에서 기간을 선택해서 현재일부터 선택기간까지 조회          
      기본값은 3년
      선택값은 3년,5년,10년
   
주식차트 : https://tradingview.github.io/lightweight-charts/ 를 사용해서 표시
         
          
화면스타일 : 앱정보화면과 같은 여백을 가지고 화면 리사이즈시 반응해서 조절
